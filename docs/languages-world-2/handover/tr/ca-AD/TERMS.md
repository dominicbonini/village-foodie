- truck (the business) → food truck (el food truck; pl. els food trucks); with a name → bare "{truck} confirmarà…", "a {truck}", "amb {truck}", "del food truck {truck}" — never "d’{truck}" / "al {truck}" / "de {truck}" (part 01, order.notOpenBody, emailCustomer.eventCancellation.body)
- Van (fleet vehicle) → vehicle (el vehicle; pl. vehicles) — never "food truck"; "Assign a truck to this event" (fleet sense) → "Assigna un vehicle a aquest esdeveniment…"; "Choose which van’s kitchen screen" → "Tria de quin vehicle vols obrir la pantalla de cuina" (part 01, dashboard.settings.assignTruck, dashboard.kds.body, emailCustomer.offlineRejectReason)
- Pay at the truck (button/option/short label) → Paga en recollir; as a payment-method status/label → Pagament en recollir; email title → "Paga en recollir, al food truck"; quoted in sentences → «Paga en recollir» / "tria Paga en recollir"; NEVER "contra reemborsament" / "pagament en el lliurament" (part 01, order.payAtTruck, orderStatus.payAtTruck, emailCustomer.payNote.hatchTitle, errorsCustomer.pay_at_hatch_unavailable)
- "at the hatch" / "at the window" → al food truck / directament al food truck ("See you at the hatch!" → "Ens veiem al food truck!"); walk-up orders → comandes presencials (part 01, order.seeYou, order.walkUpOnly, order.pausedBody)
- Place order (final customer button) → Fes la comanda; Pay {amount} → Paga {amount}; Placing order… → S’està enviant la comanda…; place an order (sentences) → fer la comanda (part 01, order.placeOrder, order.payAmount, order.placingOrder)
- Order / Orders (tab) → comanda / Comandes; Order #{id} → Comanda #{id}; Order confirmed! / Order received! → Comanda confirmada! / Comanda rebuda! (part 01, dashboard.tabs.orders, order.orderNumber, order.orderConfirmed)
- Collection / pickup → recollida; Collection time → Hora de recollida; Collection times (setting) → Hores de recollida; slot → franja; collect (verb) → recollir; ASAP → Com més aviat millor (part 01, order.collectionTimeTitle, dashboard.settings.intervalsTitle, order.asap)
- Kitchen screen → Pantalla de cuina (KDS) (label/title) / pantalla de cuina in sentences (part 01, dashboard.header.kitchenScreen, dashboard.kds.title)
- Menu (list of dishes, screen, tab) → carta; Meal deal / deal → menú (pl. menús); Meal deals → Menús; Add deal → Afegeix un menú; Apply a deal → Aplica un menú; Deal {number} → Menú {number}; already in a deal → ja és en un menú; deal slot → apartat (part 01, order.menu, order.addDeal, deals.title, deals.basketUnit)
- Save {amount} (deal saving badge) → Estalvia {amount} (lower-case estalvia {amount}) (part 01, order.save, order.dealSave, deals.save)
- + Add order (tab) → + Afegeix comanda; Menu & Stock (tab) → Carta i estoc; Settings (tab/screen) → Configuració (part 01, dashboard.tabs.*)
- Manage (section) → «Gestiona»; Manage event → Gestiona l’esdeveniment; Event → esdeveniment; Private event → Esdeveniment privat; PRIVATE EVENT → ESDEVENIMENT PRIVAT; Event type → Tipus d’esdeveniment; Standard → Estàndard; Switch to {type} → Canvia a: {type} (part 01, dashboard.eventBar.manageEvent, privateLink.guestLabel, dashboard.typePicker.*)

- Order status: New / Confirmed / Rejected / Modified / Cancelled / Cooking / Ready / Collected → Nova / Confirmada / Rebutjada / Modificada / Cancel·lada / En preparació / A punt / Recollida; lowercase: pendent, confirmada, modificada, en preparació, a punt, recollida, cancel·lada, rebutjada; Mark ready (button) → «Marca com a preparada» (part 01, dashboard.orders.status, orderStatus.statusName, dashboard.settings.orderReadyHelp)

- Kitchen capacity / prep time / batch / capacity window → Capacitat de la cuina / temps de preparació / tanda / franja de capacitat; cooked / instant (category) → es cuina / immediata (part 01, dashboard.settings.*)
