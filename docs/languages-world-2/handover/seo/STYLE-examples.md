# STYLE — Hebrew (he-IL, Israel) — RIGHT TO LEFT
- Modern Hebrew as Wolt Israel and 10bis write it. Address the operator/customer **without gendered forms where possible**: use the PLURAL imperative in instructions ("העלו תפריט", "שמרו", "הזינו"), as Tabit writes (research), infinitives/nouns for buttons ("שמירה", "העלאת תפריט"); never slash forms (ה/ת) and never masculine-singular-only imperatives. Customer copy warm, short.
- Right to left: write naturally; Latin words (HatchGrab, WhatsApp), numbers and placeholders sit inside RTL text — the browser’s bidi handles them; do NOT insert bidi control characters. Mirror arrows that mean next/back (→ becomes ←). Quotation marks: "…" written as ״…״? — use the standard " … " ONLY if no ICU risk; prefer „“? NO: use the Hebrew gershayim ״ (U+05F4) for abbreviations (מע״מ) and the typographic quotes “…” for quotations. Never a straight ' or " inside text next to a brace.
- **Prefixes:** never glue ב/ל/מ/ה/ו/ש/כ to a placeholder ("ב{truck}" ✗) — use a noun or a hyphen-free restructure: "במשאית {truck}", "עבור: {name}".
- Plural categories (CLDR he): **one, two, other** — add `two` wherever the English has a count plural (e.g. "שתי הזמנות"/"2 הזמנות").
- Phone example: 050-123-4567 (+972 50-123-4567). Postcode 7 digits (6100000). Email/domain: you@yourfoodtruck.co.il.
- Sample places: תל אביב (נמל תל אביב, שרונה), ירושלים (מחנה יהודה), חיפה (המושבה הגרמנית), באר שבע, אילת, הרצליה; venues: "שוק האיכרים", "פארק הירקון", "פסטיבל אוכל רחוב".
- Order button: "ביצוע הזמנה" / card "תשלום {amount}".
# STYLE — Serbian (sr-RS, Serbia) — LATIN SCRIPT (latinica)
- **Write in Serbian Latin script (latinica: č ć đ š ž dž lj nj)** — the research brief found Serbian businesses, delivery apps (Wolt, Glovo) and Google searches use Latin online; never mix in Cyrillic. Ekavian standard Serbian (not Croatian: "hleb" not "kruh", "uslovi", "nedelja", "kafa", "porudžbina", "podešavanja", "nalog", "lozinka", "preuzimanje"? (pickup = "preuzimanje"), "telefon/mobilni").
- Address with **Vi** (capital V in direct address is optional; use "vi"/"vaš" lower-case consistently as Wolt RS does, or polite plural forms) — polite plural imperatives ("Otpremite meni", "Sačuvajte").
- **Cases:** never put a case ending on a placeholder — apposition/colon ("food truck {truck}", "Uklonjeno: {name}").
- Plural categories (CLDR sr): **one, few, other** — "1 porudžbina", "2–4 porudžbine" (few), "5 porudžbina" (other); 21 → one, 22–24 → few, 11–14 → other. Every count plural needs all three.
- Numbers: 1.234,5; percent "20%". Phone example: +381 64 123 4567. Postcode 5 digits (11000). Email/domain: vi@vasfoodtruck.rs.
- Sample places: Beograd (Dorćol, Savamala, Ada Ciganlija, Zemun), Novi Sad (Petrovaradin), Niš, Kragujevac, Subotica; venues: "Kalemegdan", "Zeleni venac", "Street food festival", "Gradska pijaca".
- Order button: Zakon o zaštiti potrošača (2021) follows the EU rule — the button must state the obligation to pay: **"Poruči uz obavezu plaćanja"** (or "Porudžbina sa obavezom plaćanja"); card button "Plati {amount}".
# STYLE — Indonesian (id-ID, Indonesia)
- Address the OPERATOR with **Anda** (capital A), as majoo/HashMicro/Accurate write; on CUSTOMER pages (order page, status page, customer e-mails, WhatsApp replies to customers) avoid the pronoun with pronoun-free imperatives ("Pesan dulu, lalu ambil di truk"), as GoFood/GrabFood speak casually; NEVER "Bayar di tempat" (= cash on delivery); short imperative buttons without pronoun ("Unggah menu", "Simpan"). Natural Bahasa Indonesia, not Malay (use "Anda", "ponsel"/"HP", "pesanan", "unggah", "pengaturan", "akun", "kata sandi"; not Malay words like "telefon bimbit", "tetapan").
- Indonesians commonly use English loanwords in business software (food truck, pre-order, dashboard?) — prefer the Indonesian word where natural, use the loanword where the research says Indonesians search it (glossary below).
- Plural categories (CLDR id): **other** only. Indonesian doesn’t pluralise after numbers ("3 pesanan").
- Phone example: 0812-3456-7890 (+62 812-3456-7890). Postcode 5 digits (12190). Email/domain: anda@foodtruckanda.co.id.
- Sample places: Jakarta Selatan (Kemang, Senopati, SCBD), Bandung (Dago), Surabaya, Yogyakarta, Bali (Canggu, Seminyak), Medan; venues: "Car Free Day Sudirman", "Taman Kota", "Pasar Malam", "Festival Kuliner".
- Order button: "Buat pesanan" / "Pesan sekarang"; card "Bayar {amount}".
